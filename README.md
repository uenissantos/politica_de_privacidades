# Políticas de Privacidade — Uenis Programador

Site (GitHub Pages) com a política de privacidade de cada aplicativo.

- `index.html`: lista os aplicativos (lê `apps.json`).
- `calculadora-de-rotas/`: política do app Calculadora de Rotas.
- `_modelo/politica.html`: modelo para novos apps (não é publicado).
- Para adicionar outro app, veja `COMO_ADICIONAR.md`.
